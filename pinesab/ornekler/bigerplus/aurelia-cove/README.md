# AURELIA COVE / BigerPlus Bespoke

Fictional luxury hotel reference site, built as real HTML/CSS/JS pages. 19 content pages and one demo management screen. 6 primary nav pages, 3 room detail pages, 4 experience detail pages, 2 blog articles, journal, references, FAQ, about.

TR/EN/DE are individually authored `locales/*.json` files. The hero uses photo URLs from Unsplash and local SVG fallbacks. Features include intro curtains, interactive room rail, cinematic atmosphere viewer (image animation, not a real film), gallery lightbox, quote slider, date picker, built-in site messenger and demo appointment requests.

The booking/messenger forms save only on the visitor's device until a secure external Node API is deployed and configured using `config.js`. Do not use real personal information in this portfolio demo. Actual customer data requires dedicated hosting, access control, privacy compliance, storage and backups.
