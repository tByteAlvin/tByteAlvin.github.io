# MIRA NOIR / BigerPlus Bespoke

Fictional fashion-forward hair atelier website with 23 content pages, one management console, 6 main navigation items and fully hand-written Turkish/English/German locale files.

Features: cinematic editorial hero, animated curtain/route transition, glass note overlays, responsive service grid, stylist carousel, lookbook slider with modal, draggable before-after comparison of two edits to the SAME sample photograph (not a real before/after case), sample reviews, illustrative price cards, appointment request form, embedded message inbox, optional sound and motion accessibility.

All products, people, testimonials and prices are fictional/reference examples. On GitHub Pages bookings and messages are browser-local demos, not real submissions; backend deployment and secure data handling are required for actual customers.
